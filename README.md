# Dynamische offerte UGent Campus Kortrijk

Interactieve offerte voor het videoproject van UGent Campus Kortrijk, academiejaar 2026-2027.

De pagina is een rekentool: elke videoreeks uit de opdracht heeft een eigen schuifregelaar
voor **draaidagen** en **montage-uren**. De draaidagen, de postproductie, de projectkost en
het totaal bewegen live mee, met een gekleurde grafiek die toont waar het budget naartoe gaat.

## Tarieven

| Post | Tarief |
| --- | --- |
| Volledige draaidag | € 750 |
| Halve draaidag | € 450 |
| Postproductie | € 55 per uur |
| Projectkost bij opstart | € 200 eenmalig |

Van elke draaidag is 15 % voorzien voor materiaal. Dat zit in de dagprijs verrekend en
komt er niet bovenop.

## Gebruik

`index.html` is een zelfstandige pagina zonder build of dependencies. Openen in een browser
volstaat, of hem serveren via GitHub Pages.
